GETTING STARTED

Make yourself at home.

Three steps, then it’s over to you.

  1. 01

    Install Dravyn

    Open the DMG and drag Dravyn to Applications.

  2. 02

    Bring your library

    Add your own game folder and required console files. Games, firmware, and keys aren’t included.

  3. 03

    Settle in

    Connect your controller, check your bindings in Settings, and choose a game.

A note about this preview +

Dravyn is still in development. Compatibility and performance depend on the game and your Mac. Some character and reflection rendering issues remain under investigation. This download is for Apple Silicon; Intel Macs aren’t supported.

Report an issue ↗
If macOS asks before opening +

This preview is ad-hoc signed and isn’t notarized by Apple. If macOS blocks it, review the warning and use System Settings → Privacy & Security → Open Anyway only if you trust the download. You don’t need to disable Gatekeeper.
